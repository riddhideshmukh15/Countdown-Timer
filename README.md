# ⏳ Countdown Timer

A simple **Countdown Timer** project made using **Python**.
The program takes the time in seconds from the user and counts down until it reaches zero.

## 🚀 Features

* Takes time input from the user
* Counts down every second
* Displays the remaining time
* Shows a message when the timer finishes

## 🛠️ Technologies Used

* Python
* `time` module

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/riddhideshmukh15/Countdown-Timer.git
```

2. Open the project folder:

```bash
cd Countdown-Timer
```

3. Run the program:

```bash
python countdown_timer.py
```

## 💻 Example

```text
Enter time in seconds: 5

00:03
00:02
00:01

Time's up! ⏰
```
