# ⏳ Countdown Timer (Python)

## 📌 About the Project
This is a simple Countdown Timer built using Python. It allows users to enter a time in seconds and counts down until the time reaches zero.

The project includes input validation and an option to start another countdown without restarting the program.

## ✨ Features
- Enter countdown time in seconds.
- Input validation for invalid values.
- Prevents negative numbers and zero.
- Displays the countdown every second.
- Shows a "Time's up!" message when the timer finishes.
- Option to start another countdown.
- Exit the program whenever you want.

## 🛠️ Technologies Used
- Python
- Time Module
- While Loop
- Try-Except
- Conditional Statements

## ▶️ How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the Python file.
5. Enter the countdown time in seconds.
